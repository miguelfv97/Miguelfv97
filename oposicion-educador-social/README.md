**Méritos presentados:** Máster Universitario oficial en Formación del Profesorado, de 60 ECTS (Orden ECI/3858/2007). Vale **1 punto** en el concurso.

**Examen:**
- **1.ª parte:** test de 90 preguntas sobre los temarios general y específico. Vale 20 puntos y hay que sacar un mínimo de 10.
- **2.ª parte:** supuesto práctico en formato test, de 30 preguntas, a elegir entre 2 casos. Vale 40 puntos y hay que sacar un mínimo de 20.
- **Penalización:** cada error resta un tercio de acierto en las dos partes.
- **Concurso de méritos:** hasta 40 puntos.

## Cómo regenerar los PDF (carpeta `herramientas/`)

```bash
pip install markdown
```

```bash
python3 oposicion-educador-social/herramientas/build.py oposicion-educador-social/fuentes/01_general_I_temas_1-6.md oposicion-educador-social/01_General_I_Temas_1-6.pdf "General I · Temas 1–6"
```

- `build.py` convierte el Markdown a PDF A4 con Chromium (Playwright). Usa los bloques `::: info|claves|aviso Título` … `:::`.
- `art.py` extrae artículos de una ley descargada del BOE como texto, para comprobar las citas: `python3 art.py ley.txt 1500 39 40`.
